# Student Information System

## Overview
A desktop application developed using C# Windows Forms
and MySQL for managing student records.

## Features
- Login and Sign Up
- Dashboard
- Add, View, Edit, and Delete students
- Search student records
- User Profile
- User-specific student records

## Technologies Used
- C#
- Windows Forms
- Visual Studio
- MySQL

## Requirements
- Windows
- Visual Studio
- MySQL Server

## Setup
1. Clone or download the project.
2. Create the MySQL database.
3. Configure the database connection.
4. Install the required NuGet packages.
5. Run the project in Visual Studio.
