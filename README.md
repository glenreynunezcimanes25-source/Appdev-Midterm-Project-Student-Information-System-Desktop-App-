# Student Information System

## Overview
A desktop application developed using C# Windows Forms
and MySQL for managing student records.

## Group Members
- Glen Rey Cimanes: UI Layout & DataGridView Display.
- Timothy Garcia: MySQL Setup & Database Connection.
-  Clark Boncodin: CRUD Logic (Add, Edit, Delete).
  ### GitHub repository link
- https://github.com/glenreynunezcimanes25-source/Appdev-Midterm-Project-Student-Information-System-Desktop-App-.git
  

## Features
- Login and Sign Up
- Dashboard
- Add, View, Edit, and Delete students
- Search student records
- Table export
  
## Technologies Used
- C#
- Windows Forms
- Visual Studio
- MySQL

## Requirements
- Windows
- Visual Studio
- MySQL Server

## Setup
1. Clone or download the project.
2. Create the MySQL database.
3. Configure the database connection.
4. Install the required NuGet packages.
5. Run the project in Visual Studio.
